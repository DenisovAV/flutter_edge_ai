# Package Skills codelab — finished app

The reference for
[Package Skills in Flutter](https://flutteredge.ai/codelabs/package-skills-flutter-gemma)
after Step 4: an offline chat on Gemma 4 E2B that can change the app's colour
by calling a Dart function. Your assistant's code will not match it line for
line; check it against the codelab's lists instead.

```bash
flutter test                                   # the colour tool, without a model
flutter test integration_test/skills_test.dart -d <device-id>   # ~2.6 GB download
```
