# ADR 0001: Record architecture decisions

**Status:** accepted · **Date:** 2026-10-04

## Context

The project's value as a portfolio piece rests on visible engineering judgment. Decisions
need to be findable and dated.

## Decision

Keep architecture decision records in `docs/adr/`, numbered, one decision per file, using
the sections Context, Decision, Consequences. A decision starts as `proposed` and becomes
`accepted` when the owner confirms it in `QUESTIONS.md` or `TECH_QUESTIONS.md`.

## Consequences

Small overhead per decision. Reviewers can trace why the design looks the way it does.
