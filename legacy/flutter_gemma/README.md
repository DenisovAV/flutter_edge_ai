> ## ⚠️ Renamed to [`flutter_edge_ai`](https://pub.dev/packages/flutter_edge_ai)
>
> `flutter_gemma` is no longer developed and this is its final release. New features and fixes ship as [`flutter_edge_ai`](https://pub.dev/packages/flutter_edge_ai), part of [Flutter Edge AI](https://flutteredge.ai).
>
> To migrate, replace the `flutter_gemma` dependency with `flutter_edge_ai`, change imports from `package:flutter_gemma/flutter_gemma.dart` to `package:flutter_edge_ai/flutter_edge_ai.dart`, and run `dart fix --apply`. Installed models and app data carry over. See the [migration guide](https://flutteredge.ai/docs/migration).
