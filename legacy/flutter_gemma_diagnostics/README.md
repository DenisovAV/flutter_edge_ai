>
> To migrate, replace the `flutter_gemma_diagnostics` dependency with `flutter_edge_ai_diagnostics`, change imports from `package:flutter_gemma_diagnostics/flutter_gemma_diagnostics.dart` to `package:flutter_edge_ai_diagnostics/flutter_edge_ai_diagnostics.dart`, and run `dart fix --apply`. Installed models and app data carry over. See the [migration guide](https://flutteredge.ai/docs/migration).
