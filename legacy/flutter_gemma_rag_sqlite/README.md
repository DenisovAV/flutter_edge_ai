> ## ⚠️ Renamed to [`flutter_edge_ai_sqlite`](https://pub.dev/packages/flutter_edge_ai_sqlite)
>
> `flutter_gemma_rag_sqlite` is no longer developed and this is its final release. New features and fixes ship as [`flutter_edge_ai_sqlite`](https://pub.dev/packages/flutter_edge_ai_sqlite), part of [Flutter Edge AI](https://flutteredge.ai). Version 2.0 of the new family also moves RAG into [`flutter_edge_ai_rag`](https://pub.dev/packages/flutter_edge_ai_rag): add it next to `flutter_edge_ai_sqlite`.
>
> To migrate, replace the `flutter_gemma_rag_sqlite` dependency with `flutter_edge_ai_sqlite`, change imports from `package:flutter_gemma_rag_sqlite/flutter_gemma_rag_sqlite.dart` to `package:flutter_edge_ai_sqlite/flutter_edge_ai_sqlite.dart`, and run `dart fix --apply`. Installed models and app data carry over. See the [migration guide](https://flutteredge.ai/docs/migration).
>
