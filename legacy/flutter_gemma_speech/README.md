> ## ⚠️ Renamed to [`flutter_edge_ai_speech`](https://pub.dev/packages/flutter_edge_ai_speech)
>
> `flutter_gemma_speech` is no longer developed and this is its final release. New features and fixes ship as [`flutter_edge_ai_speech`](https://pub.dev/packages/flutter_edge_ai_speech), part of [Flutter Edge AI](https://flutteredge.ai).
>
> To migrate, replace the `flutter_gemma_speech` dependency with `flutter_edge_ai_speech`, change imports from `package:flutter_gemma_speech/flutter_gemma_speech.dart` to `package:flutter_edge_ai_speech/flutter_edge_ai_speech.dart`, and run `dart fix --apply`. Installed models and app data carry over. See the [migration guide](https://flutteredge.ai/docs/migration).
